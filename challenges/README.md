# After the workshop
These are pure starter functions for editing in your own fork, not executable inputs to the browser console. Begin by changing a constant or adding one condition. The corresponding source module is named in each file. Import your function into that module and replace the equivalent rule. Leave camera and model infrastructure alone.

1. Fork and clone the repository. Install Node.js 22 or newer.
2. Run `npm ci` and `npm run dev`.
3. Change one function. Add a deterministic test to `tests/core.test.js` that shows its new behavior.
4. Run `npm test`, `npm run build`, and test the lab in Chrome.
5. Share your fork and explain your prediction, experiment, and result.

Object challenge: give bottles a threshold of 0.3 but people a threshold of 0.8. Expression challenge: add a brows-up rule using `browInnerUp`. Gesture challenge: compare release multipliers 1.05 and 1.5. Arcade challenge: award 10 points for gold orbs. See source modules for integrating these functions.
